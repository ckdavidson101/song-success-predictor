# Song Success Predictor

End-to-end project to predict Spotify-style track success and run "what-if" simulations.
- Backend: FastAPI (ETL, model serving)
- ML: training, translators, notebooks
- Frontend: Next.js (UI)
- Infra: docker-compose (db/cache, optional MLflow)

## Quick start
- `make setup` to bootstrap envs
- `make dev` to run backend & frontend
